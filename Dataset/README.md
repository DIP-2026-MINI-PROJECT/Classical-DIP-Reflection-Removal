# Dataset

This project uses a self-created dataset consisting of indoor glass photographs containing reflections and glass-ghost effects.

The images were collected to test reflection candidate detection, manual mask refinement, and reflection suppression using 
classical Digital Image Processing techniques.

The dataset contains different reflection conditions, including:
- Bright reflections
- LED/sunlight/flash reflections
- Objects and people reflected on glass
- Background and environmental reflections
- Glass-ghost effects
